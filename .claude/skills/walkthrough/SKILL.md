---
name: walkthrough
description: Run when I say "walk me through it" (or similar). Turns the list, plan or instructions just given into a guided step-by-step walkthrough. Also load it for any item-by-item review.
---
- Before the first item, load every skill the items' subject calls for (build-3dp for a design), and follow it for each item.
- One item per message, headed "Step N of M". Exception: consecutive trivial steps with no decision and no exact value (e.g. "open Settings," then "click Save") can share one message. If order matters, sort the items and say why.
- In a walkthrough or any item-by-item review, each new item starts on its own line, apart from any note about the previous one, in replies and card context alike.
- Each item gives, each part under a bold label: **What and why:** what it is and why; **Where:** where to find it or how to do it; **Exact values:** the exact value, amount or action; **Question:** what I need to answer. The "Step N of M" header is bold too.
- End each item with the questions I need to answer before moving on. If there are several, list them all first without options, then ask them one card at a time.
- Move on only when I confirm the step is done. If an answer changes a later step, update it and say what changed.
- Save each item's agreed outcome to the product doc's agreed changes when it's agreed (repo-edit), never only in a project-folder report.
- If there's nothing for me to do, only something to understand, explain it instead.
