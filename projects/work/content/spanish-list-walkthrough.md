# Spanish Negatives: simplification (review complete 2026-09-29)
Companion to negative-keyword-audit.md. Replaces legacy list #5 "Delta - Spanish Negatives for English Campaigns" (260 entries; Brand ×4, NB ×4).

Purpose (user): block Spanish-language searches.

Word decisions:
- Still avoided (prospects type them): boca (Boca Raton), el (El Paso), de (Delaware), la (Louisiana), top, local, ppo, medicare, aarp, delta, plan, seniors, state names and abbreviations.
- Fine to use: para, planes, red, costo, sin, en, que, un, mas.

Legacy list findings:
- 260 entries = 130 keywords, each as both EXACT and PHRASE (EXACT copies are redundant).
- "Missing Keywords" (EXACT + PHRASE) is a placeholder, not Spanish: removed.
- No legacy entry blocks English prospect searches (every phrase contains a Spanish word).
- Accented and unaccented forms are both included.
