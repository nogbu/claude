# photos.unicoly

One line per photo in the 3dp project folder, /mnt/project-files/photos/unicoly/. Files are PXL_<date>_<time><ms>.jpg; names here drop PXL_ and the milliseconds. Last reconciled with the folder: 2026-09-30 15:50, 78 photos.

**How to use it.** Search for the feature (lip, slot pitch, caliper, clip). For new or removed photos, compare a folder listing with the names here. Each measurement in unicoly or a product doc cites its photo by name.

**Legend.** WS = ClosetMaid MaxLoad wire shelf section. CAB = UNICOLY cabinet. Scale = the reference in the frame and whether it's in the feature's plane (only in-plane scales give trustworthy sizes). Measured values are from the photo, in mm. Status: used (feeds a doc), check (agrees with a used photo), available (measurable, not measured), context (no measurement), superseded, unusable.
